# THE IMPOSTOR

Everyone knows the word. Except one.

A multiplayer social deduction game for 4 to 6 players. Everyone gets a secret word, but the Impostor gets a word from a different category. Players give hints over 3 rounds, then vote for who they think the Impostor is.

## How to play
1. One player creates a room and shares the room code.
2. 4 to 6 players join with the code.
3. Each player sees only their own secret word. The Impostor sees a red IMPOSTOR title.
4. Take turns giving a hint without saying your word.
5. Vote for the Impostor. The Impostor gets one last guess at the real word.

## Scoring
- Voting for the Impostor: +20
- Impostor not caught: +30
- Impostor guesses the word: +15

## Run it on your computer
1. Install Node.js from nodejs.org
2. In this folder, run: npm install
3. Then run: node server.js
4. Open http://localhost:3000
